# TED as the sole data source

tender-scout ingests tenders only from TED (Tenders Electronic Daily), the EU's
official publication channel for above-threshold public contracts. We deliberately
exclude the 27 national procurement portals, which each have different formats, access
rules, and coverage. TED gives EU-wide coverage from one well-documented, legally clean
API with no scraping. National portals would widen coverage to below-threshold
contracts but are an additive future improvement, not part of the core model.
